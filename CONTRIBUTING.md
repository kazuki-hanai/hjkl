# Contributing

Thanks for your interest in contributing to `hjkl-for-mac`.

## Development

Commands and the Rust toolchain are managed with [mise](https://mise.jdx.dev).
Install mise once, then let it set up the toolchain:

```sh
mise install          # install the pinned toolchain from mise.toml
mise tasks            # list available tasks
mise run ci           # macOS CI: common Rust checks plus shell script checks
mise run ci-core      # cross-platform Rust checks used by Windows CI
```

Individual tasks are also available, e.g. `mise run fmt`, `mise run lint`,
`mise run test`. CI runs `mise run ci` on macOS and `mise run ci-core` on
Windows. The tasks are thin wrappers over `cargo` (see `mise.toml`) if you
prefer to run cargo directly.

The OS abstraction layer is `src/platform.rs`. Shared CLI behavior routes to
`src/macos/` or `src/windows/`, while the layer state machine stays in
`src/keymap.rs`. The LaunchAgent plist is generated by the binary itself
(`src/macos/service.rs`), and the Windows scheduled task command is generated in
`src/windows/service.rs`.

## Pull requests

Please include:

- a short description of the user-visible behavior change,
- tests or a clear manual verification note,
- any macOS permission, LaunchAgent, Windows hook, or scheduled-task
  implications.

## Security-sensitive changes

This project installs per-user auto-start entries and reads keyboard events
through macOS Accessibility APIs or a Windows low-level keyboard hook. Please
keep changes small and explain why new permissions, background behavior, or
file-system writes are necessary.

## Releasing

Releases are automated by `.github/workflows/release.yml`, which runs when a
`v*` tag is pushed.

1. Update the version in `Cargo.toml` and move the `CHANGELOG.md`
   `[Unreleased]` entries under a new version heading.
2. Land those changes on `main` through a pull request.
3. Tag the release commit and push the tag:

   ```sh
   git tag v0.1.0
   git push origin v0.1.0
   ```

The workflow verifies the tag matches the `Cargo.toml` version, builds macOS and
Windows release binaries, publishes macOS `.tar.gz` and Windows `.zip` archives
with `.sha256` checksums, and attaches build provenance attestations.
